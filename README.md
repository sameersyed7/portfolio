# Sameer Syed — Linux & DevOps Engineer Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript. It is ready for GitHub Pages and requires no build system.

## Customize before publishing

Edit `index.html` and replace:
- GitHub URL
- LinkedIn URL
- Email address
- Experience wording
- Project descriptions/links
- Skills and technologies

The GreenCart repository link is already included as an example.

## GitHub Pages deployment

1. Create a GitHub repository, e.g. `devops-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `.nojekyll`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Actions to finish.
7. Your site will be available at:
   `https://YOUR-USERNAME.github.io/devops-portfolio/`

No npm install or build command is required.
